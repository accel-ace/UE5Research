# GameState

## 概要

GameStateは、ゲーム全体で共有する状態を保持するクラスです。

Gameplay Frameworkでは、ゲームの進行状況やスコア、制限時間など、すべてのプレイヤーが共通で参照する情報を管理します。

GameStateはサーバーで管理され、必要な情報が各クライアントへ同期されます。

## 主な役割

* ゲーム全体の状態を保持する
* クライアントへ状態を同期する
* ラウンド情報の管理
* 制限時間の管理
* チームスコアの管理

## GameStateの特徴

### ゲーム全体の状態を管理する

現在のゲームの状況を保持します。

例

* 制限時間
* ラウンド数
* チームスコア
* 試合開始・終了状態

### クライアントと共有できる

GameStateの情報は、サーバーから各クライアントへ同期されます。

そのため、すべてのプレイヤーが同じゲームの状態を確認できます。

### GameModeとは役割が異なる

GameModeはゲームのルールを決定します。

GameStateは、そのルールに基づいて現在のゲーム状態を保持・共有します。

## Gameplay Frameworkでの位置付け

```text
GameMode
     │
     ▼
 GameState
     │
 ┌───┴────┐
 ▼        ▼
Client1  Client2
```

GameModeが更新したゲーム全体の状態をGameStateが保持し、各クライアントへ共有します。

## GameModeとの違い

| GameMode       | GameState         |
| -------------- | ----------------- |
| ゲームルールを管理する    | ゲーム全体の状態を保持する     |
| サーバーのみ存在する     | サーバーとクライアントで共有される |
| 勝敗判定やスポーン処理を行う | スコアや制限時間などを保持する   |
