# PlayerState

## 概要

PlayerStateは、各プレイヤー固有の情報を保持するクラスです。

Gameplay Frameworkでは、プレイヤー名やスコアなど、プレイヤーごとに管理する情報を保持します。

PlayerStateはサーバーで管理され、必要な情報が各クライアントへ同期されます。

## 主な役割

* プレイヤー情報の保持
* スコアの管理
* チーム情報の管理
* プレイヤーごとの状態の共有

## PlayerStateの特徴

### プレイヤーごとの情報を管理する

各プレイヤー専用の情報を保持します。

例

* プレイヤー名
* スコア
* キル数
* デス数
* チーム番号

### クライアントへ同期される

PlayerStateの情報はサーバーから各クライアントへ同期されます。

そのため、他のプレイヤーのスコアや名前などを表示できます。

### Pawnが変更されても情報を保持できる

PlayerStateはPawnとは別のオブジェクトです。

そのため、プレイヤーがリスポーンしたり、操作するPawnが切り替わった場合でも、プレイヤー情報を維持できます。

## Gameplay Frameworkでの位置付け

```text
PlayerController
       │
       ▼
PlayerState
       │
       ▼
     Pawn
```

PlayerControllerがプレイヤーを管理し、PlayerStateがプレイヤー固有の情報を保持し、Pawnが実際のゲーム内キャラクターとして動作します。

## GameStateとの違い

| GameState            | PlayerState         |
| -------------------- | ------------------- |
| ゲーム全体の状態を管理する        | プレイヤーごとの状態を管理する     |
| 制限時間・ラウンド・全体スコアなどを保持 | プレイヤー名・スコア・キル数などを保持 |
| 全プレイヤー共通の情報          | 各プレイヤー固有の情報         |
